## How to use this list

1. Open the thread link, find the message by date and sender, and download the file named.
2. Drop it into `Raw/` (Drive folder `1ntYVPRv8xacjjIYqrMi9EVBVv_0PUzuj`) **unrenamed**. The next
   session registers it, renames nothing, and works it into the Wiki.
3. Every file here is Drive-only and is never committed to git (section 6b of `CLAUDE.md`).
4. Where a password is needed it is the scheme's PSTR (the administrator's email of 19/01/2023).
5. Signable and Xero send links as well as, or instead of, attachments; those rows say so.
6. Do not save anything marked **member-personal** into `Raw/`; those rows are listed only so the
   thread is not searched again.

Tick the box in the first column as each item is saved; the file is then replaced with the ticked
version.
