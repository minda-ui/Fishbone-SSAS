## What this means for this KB

The certificate exists and is genuine, but it is **the principal employer's own document, not this
scheme's**, so per `CLAUDE.md` section 1's cross-entity rule ("linked, never copied, so there is
one place to correct each fact") it is **not copied into this KB's `Raw/`**. `Wiki/Employers/
fishbone-construction-ltd.md` is updated to link to it directly (Drive URL) rather than duplicate
it, and its own open-questions list marks the certificate question resolved.

This also is not a `§7a` hand-off case: that mechanism is for routing a document *into* a KB that
should hold it as its own (e.g. group post-room mail); here the document already correctly belongs
to, and already correctly sits in, the Fishbone Construction Ltd KB. Copying it here would create
two stored copies of the same fact, which section 1 and section 6b both rule out.
